# Human playtest checklist

Play **at least two raids of each mode** (menu → RNG RAID, then CHAOS / GRIEF RAID), at normal speed and with sound on.
Debug panel (` key or the tiny DBG button) can reset the save so the first-session callouts show again.

Score each 1–5 and add a one-line "why".

**Watching / pulling**
- [ ] Was watching other players roll entertaining?
- [ ] Did Legendary rolls feel special (yours *and* other people's)?
- [ ] Was your own bad roll funny/frustrating rather than simply annoying?

**Chaos phase**
- [ ] Did you want to reroll?
- [ ] Was Shuffle scary enough?
- [ ] Did you understand stealing immediately?
- [ ] Did stealing feel exciting (the dial)?
- [ ] Was griefing funny or just irritating — when *you* did it? when it was done *to* you?
- [ ] Would you personally pay soft currency to grief someone?

**Raid pot**
- [ ] Did the raid pot create peer pressure?
- [ ] Did you want other players to boost it?
- [ ] Did x2 (CHAOS RAID) feel dangerous enough?

**Place + payoff**
- [ ] Did you care about the other lobby characters?
- [ ] Was the pre-match lobby more fun than a normal loadout screen?
- [ ] Did entering the dungeon make the lobby choices feel worthwhile?

**V2 — new systems**
- [ ] Was the simultaneous reveal (all 8 reels, one-by-one landings, "still spinning…") more fun than V1's staggered rolls?
- [ ] Did PROTECT feel like a real decision? Did you ever regret it / did a WARD BROKEN moment land?
- [ ] Did the LOADOUTS LOCKED pause help you read the lobby before the raid?
- [ ] Did the boon votes create any co-op/social tension? Did you notice the bots herding?
- [ ] Did the race position make you care about the fight minute-to-minute?
- [ ] Did battle items feel Mario-Kart-ish — comebacks, "NOT THE STAFF", leaders getting hunted?
- [ ] Lightning at 3.5s: too weak / right / try 5 or 10 (debug panel)?
- [ ] Was "we're technically on the same team…" the feeling?
- [ ] Did the podium + placement rewards make 1st vs 4th matter?

**Verdict**
- [ ] Which was better: **RNG RAID** or **CHAOS / GRIEF RAID**? Why?

Also note: anything you couldn't read at phone size, any moment you didn't know what to press, and how long a full
lobby felt (target ≈60s).
